Overview

Project Summary

S
Situation

As part of the ODSC × Google Cloud Agentic AI Hackathon, teams were challenged to solve real-world problems with agentic AI. Early-stage Alzheimer's patients face challenges with short-term memory and routine adherence, while caregivers lack continuous personalized support tools.

T
Task

Design an AI-driven assistant capable of providing proactive reminders, contextual memory support, and natural conversational assistance — while adapting to evolving user behavior.

A
Action

Implemented an agentic planner–executor–memory architecture using Google Gemini APIs, enabling the system to decompose goals, maintain long-term memory, and dynamically adapt responses based on user context and interaction history.

R
Result

Delivered a working agentic AI prototype with multi-step reminder workflows, persistent memory across sessions, and context-aware responses. Selected among the top 6 teams out of 80 at the ODSC × Google Cloud Hackathon.
