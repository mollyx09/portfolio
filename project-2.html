Memory Anchor

An agentic AI companion designed to support early-stage Alzheimer’s patients through routine reminders, contextual memory recall, and adaptive conversational assistance.

View Implementation

Project Overview

Situation: As part of the ODSC x Google Cloud Agentic AI Hackathon, teams were challenged to design practical agentic AI systems that solve real-world problems using modern LLM-based architectures. Early-stage Alzheimer’s patients face challenges with short-term memory, routine adherence, and contextual recall, while caregivers lack continuous, personalized support tools.

Task: Design an AI-driven assistant capable of providing proactive reminders, contextual memory support, and natural conversational assistance while adapting to evolving user behavior.

Action: Implemented an agentic planner–executor–memory architecture using Google Gemini APIs, enabling the system to decompose goals, maintain long-term conversational memory, and dynamically adapt responses based on user context and interaction history.

Result: Delivered a working agentic AI prototype capable of executing multi-step reminder workflows, maintaining persistent user memory across sessions, and generating context-aware responses with improved continuity during extended interactions. The project was selected among the top 6 teams in the ODSC x Google Cloud Agentic AI Hackathon, validating both technical execution and real-world relevance.
