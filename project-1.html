Overview

Project Summary

S
Situation

RAG systems require scalable indexing pipelines that handle large document corpora with semantic search, graph-based reasoning, and incremental updates. Traditional single-stage pipelines struggle with cost and latency at scale.

T
Task

Design a production-style distributed indexing system capable of processing 600+ MSR research papers, supporting batch, micro-batch, and streaming ingestion models.

A
Action

Architected as a progressive distributed pipeline: Hadoop MapReduce on AWS EMR → Apache Spark + Delta Lake → Apache Flink on AWS EKS with Neo4j knowledge graph construction and Akka HTTP REST APIs.

R
Result

85% reduction in batch processing time · 70% reduction in compute and storage costs · sub-second P95 query latency · <2s end-to-end QA latency
