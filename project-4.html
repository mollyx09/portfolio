Overview

Project Summary

S
Situation

The rapid adoption of LLM-based coding assistants raises a key question for production teams: when does multi-agent orchestration actually outperform a well-engineered single-agent system? Existing literature lacks controlled, cost-aware comparisons across standardized benchmarks.

T
Task

Design and execute an empirical study comparing single-agent and multi-agent LLM architectures for automated code generation and requirements engineering — measuring accuracy, token cost, and repair efficiency.

A
Action

Architected 3 LLM pipeline systems using LangGraph and LangChain, powered by Claude Sonnet. Engineered 6 specialized agents (Planner, Extractor, Critic, Coder, Test Runner, SME Advisory) with budget-guard constraints. Evaluated across 1,282+ tasks on HumanEval+, MBPP+, BigCodeBench-Hard, PURE, and NICE datasets.

R
Result

100% pass@1 on HumanEval+ and MBPP+ · 0.781 Semantic F1 on RE tasks · Derived cost-efficiency deployment guidelines for production LLM systems. Study ongoing (Jan 2026 – Present).
